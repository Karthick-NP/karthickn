# Karthick N — Portfolio

🔗 **Live Site:** https://karthick-np.github.io/karthickn/

Personal portfolio website built to showcase my projects, skills, and journey as a Full Stack Java Developer. Designed with a dark, GitHub-inspired aesthetic and smooth interactive elements.

---

## 📌 About

I'm a recent B.Tech Information Technology graduate from Ganesh College of Engineering, Salem, Tamil Nadu (affiliated with Anna University, Chennai), with a strong focus on **Full Stack Java Development**. This portfolio highlights my technical skills, completed projects, and resume — built to support my placement and job search journey.

---

## ✨ Features

- 🌗 **Dark / Light Mode Toggle** — switch themes based on preference
- ⌨️ **Typing Animation** — dynamic intro text effect
- 🎬 **Scroll-Reveal Animations** — sections animate smoothly into view while scrolling
- 🖥️ **GitHub-Inspired Dark Theme** — clean, developer-centric design
- 📱 **Responsive Layout** — works across desktop, tablet, and mobile
- 📂 **Project Showcase** — detailed cards for each project with tech stack and links
- 📄 **Resume Access** — downloadable/viewable resume
- 📬 **Contact Section** — easy ways to reach out / connect

## 🚀 Getting Started (Run Locally)

```bash

# Navigate into the project folder
```

No build tools or dependencies required — this is a static site.
